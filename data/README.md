# Data

Put `cookie_cats.csv` in this folder (not committed to the repo).

```bash
curl -L -o data/cookie_cats.csv "https://raw.githubusercontent.com/yanny-alt/Cookie-Cats-A-B-Testing-Project/main/data/cookie_cats.csv"
```

Or download it from Kaggle by searching "Mobile Games A/B Testing Cookie Cats".

The file should have 90,189 rows and these columns:
`userid, version, sum_gamerounds, retention_1, retention_7`.
